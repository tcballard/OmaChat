# OmaChat

OmaChat is a planned always-on, bitchat-compatible mesh node and terminal client for Arch Linux and Omarchy.

The project is currently in validated planning. Implementation begins with the source and feasibility gate; protocol behavior is pinned to named upstream releases and must pass cross-implementation fixtures or live-peer tests before it is trusted.
